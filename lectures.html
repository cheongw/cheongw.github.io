Python Applications for Chemists

Description: This lecture series is based on Charles J. Weiss’s Scientific Computation for Chemists with Python and presents key concepts and code examples through practical, real-world chemistry applications. Topics include numerical computation, symbolic mathematics, image analysis, chemical kinetics simulation, optimization, and machine learning.

Lecture Topics

  • Topic 1: Python Basics Overview for Chemists
  • Topic 2: SymPy Basics for Chemists
  • Topic 3: Image Processing & Analysis
  • Topic 4: Chemical Kinetics & Radioactive Decay
  • Topic 5: Optimization and Root Finding
  • Topic 6: Regression or Curve-Fitting
  • Topic 7: Machine Learning (ML) - A Typical Process of Building a ML Model
  • Topic 8: Machine Learning (ML) - Classification
  • Topic 9: Machine Learning (ML) - Blind Signal Separation

Chem-Informatics

Description: This lecture series offers a comprehensive introduction to ChemInformatics — a multidisciplinary field at the intersection of chemistry, data science, and computer science, and a key component of the fourth paradigm of scientific discovery. It features hands-on use of the RDKit Python library for chemical structure visualization, molecular property extraction, structural pattern search, and QSPR/QSAR modeling. The series also introduces a range of molecular featurization techniques.

Lecture Topics

  • Topic 1: Visualizing Chemical Structure
  • Topic 2: Visualizing Stereoisomers
  • Topic 3: Using SMILES input without stereochemical notations
  • Topic 4: Extracting & Searching Molecular Information
  • Topic 5: Pattern Search; Atoms and Bonds
  • Topic 5: Molecular Pattern Search
  • Topic 6: Summary of Topics 1-5
  • Topic 7: Cheminformatics Backgrounds
  • Topic 8: Structure-Property Relationship
  • Topic 9: Molecular Descriptors
  • Topic 10: Building a DataFrame with the Molecular Descriptors
  • Topic 11: Multiple Regression
  • Topic 12: Molecular Similarity, 0D Molecular Descriptors, and Featurization
  • Topic 13: 1D Molecular Descriptors (MACCSKeys and PubChem Fingerprint)
  • Topic 14: 1D & 2D Molecular Descriptors and Featurization
  • Topic 15: Graph Convolution Featurization
  • Topic 16: Molecular Similarity Coefficients & Similarity Comparison
  • Topic 17: How Similar is Similar?

Bio-Informatics

Description: This YouTube series offers an accessible introduction to bioinformatics with hands-on coding examples using BioPython. Starting from basic sequence handling and digital representations of transcription and translation, the series progresses to protein structure analysis, visualization, and protein-ligand interactions. Later sessions explore predictive modeling using machine learning and real-world applications such as ligand-based virtual screening in drug discovery.

Lecture Topics

  • Topic 1: A FASTA File, Sequence Object, and Sequence Extraction
  • Topic 2: Digital Analogues of Nucleic Acid Processes: Transcription and Translation
  • Topic 3: Protein
  • Topic 4: Accessing Parts of Proteins
  • Topic 5: Accessing Further Details of Proteins
  • Topic 6: Visualizing Proteins
  • Topic 7: Protein-Ligand Binding
  • Topic 8: Protein-Ligand Binding Affinity Model
  • Topic 9: Protein-Ligand Binding Affinity Model (2)
  • Topic 10: Ligand-Based Virtual Screening & Compound Filter
