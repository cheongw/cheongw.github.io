Python Basics

These are the private YouTube sessions requiring the instructor's permission:

  • Python Basics for Chemists

    This YouTube session introduces key Python concepts tailored for chemists for their numerical computations and graphing, covering: 1. Assigning values to variables. 2. Performing operations with different variable types. 3. Utilizing popular Python libraries, including NumPy, Pandas, and Matplotlib.

  • SymPY Basics for Chemists

    This YouTube session introduces basic SymPy symbolic mathematics.

  • Image Processing & Analysis

    This YouTube session delves into image processing and analysis using one of Python’s powerful libraries, Scikit-Image. Topics covered include 2D and 3D image arrays, image format conversion, contrast enhancement, pattern detection, and more.

  • Chemical Kinetics & Radioactive Decay

    This YouTube session covers both deterministic and stochastic simulations. As an example of deterministic simulation, a couple of chemical kinetics simulations are demonstrated. For stochastic simulation, a radioactive decay model is discussed.

  • Optimization and Root Finding

    This YouTube session explored two different optimization problems: Minimization and Root Finding. We demonstrated examples of both in solving the problems of quantum mechanics and organic chemistry. The minimization and root finding were achieved using the optimized module's built-in functions.

  • Regression or Curve-Fitting

    This YouTube session explores the curve_fit() function from the scipy.optimize module, which is used for both linear and nonlinear regression. The session also introduces a manual approach to linear regression using matrix algebra, providing insight into the underlying mechanics of regression analysis.

  • A Typical Process of Building a Machine Learning (ML) Model

    In this YouTube session, we walk through a typical machine learning workflow—covering data exploration, data preprocessing, model training, evaluation, and prediction —using a simple, hands-on code example.

  • Machine Learning (ML) - Classification

    This YouTube session discusses the concept of clustering using both supervised and unsupervised learning approaches, with simple code examples.
