YouTube Sessions

These are private YouTube sessions requiring the instructor's permission:

  • Python Basics for Chemists

    This YouTube session introduces key Python concepts tailored for chemists for their numerical computations and graphing, covering: 1. Assigning values to variables. 2. Performing operations with different variable types. 3. Utilizing popular Python libraries, including NumPy, Pandas, and Matplotlib.

  • Session 0 Part 1: Visualizing Chemical Structure

    This YouTube session shows how to visualize chemical structures using Python's library, RDKit.

  • Session 0 Part 2: Cheminformatics - Visualizing Stereoisomers

    This YouTube session explains how to visualize stereoisomers using Python and the RDKit library. It discusses R and S isomers and Z and E isomers.

  • Session 0 Part 3: Cheminformatics - Using SMILES input without stereochemical notations.

    This YouTube session builds upon our understanding of stereochemistry. It addresses some limitations of analyzing stereochemistry using the RDKit library, particularly when molecules are represented in the SMILES format without stereochemical notations. Additionally, we demonstrate techniques for visualizing molecular structures while incorporating their stereochemical details.

  • Session 0 Part 4: Cheminformatics - Extracting & Searching Molecular Information

    This YouTube session explains how to extract molecular properties, features, and patterns from a molecule using RDKit.

  • Session 0 Part 5: Cheminformatics - Pattern Search; Atoms and Bonds

    This YouTube video explores an alternate approach to performing a pattern search and shows how to access and modify specific atoms and bonds within a molecule.

  • Session 0 Part 5.5 (=old Session 8.5) Cheminformatics - Molecular Pattern Search

    This YouTube video shows how to perform a molecular pattern search by using the Python library, RDKit.

  • Session 0 Part 6: Cheminformatics Summary

    This YouTube video summarized topics discussed in the 5 parts of session 0. The topics are SMILES, Molecular Loader, Molecule Visualization, Stereochemistry, Visualization with Stereochemical Notations, Descriptors, Molecular Pattern Search, Carbon 13 Labelling, Breaking Bonds, and Assigning Charges.

  • Session 1: Cheminformatics - Backgrounds

    This YouTube session provides a brief introduction to the fourth paradigm: eScientists working on cheminformatics. We also explored cheminformatics’ origins and its place within the broader scientific paradigm. Additionally, we covered the fundamentals of data and introduced the key basics of Python programming.

  • Session 2: Cheminformatics - Structure-Property Relationship

    This YouTube video explains how the "Structure-Property Relationship" is applied in quantitative property prediction through a technique known as Machine Learning.

  • Session 3: Cheminformatics - Molecular Descriptors

    This YouTube video discusses several molecular descriptors; Wiener Index, Zagreb Index 1, and Zagreb Index 2, which are related to the boiling point of alkanes.

  • Session 4: Cheminfomatics - Building a DataFrame with the Molecular Descriptors

    In this YouTube session, we will learn how to leverage the 'for loop' structure further to compute many 2D molecular descriptors using a DataFrame containing extensive data.

  • Session 5: Cheminformatics - Multiple Regression

    This YouTube video delves into building a predictive model to determine boiling points by consolidating key molecular descriptors: molecular weight, Wiener index, and Zagreb indices. The consolidation technique employed is multiple regression.

  • Session 6: Cheminformatics - Molecular Similarity, 0D Molecular Descriptors, and Featurization

    This YouTube session discusses the term "molecular similarity," a couple of categorizations for the molecular descriptors, and one of several functionalization methods, RDKitDescriptors.

  • Session 7: Cheminformatics - 1D Molecular Descriptors (MACCSKeys and PubChem Fingerprint)

    This YouTube video discusses the 1-D molecular descriptors: MACCSKeys and PubChem Fingerprint.

  • Session 8: Cheminformatics - 1D & 2D Molecular Descriptors and Featurization

    This YouTube session discusses 1D (Path-Based FP) & 2D (Circular FP) Molecular Descriptors and Featurization.

  • Session 9: Cheminformatics - Graph Convolution Featurization

    This YouTube video explores graph convolution featurization and introduces a simplified solubility prediction model derived from Delaney's data and GraphConvModel() function.

  • Session 10: Cheminformatics - Molecular Similarity Coefficients & Similarity Comparison

    This YouTube lesson discusses molecular similarity coefficients and explores how to compare similarity with the metrics.

  • Session 11: Cheminformatics - How Similar is Similar?

    This YouTube lesson probabilistically demonstrates how similar the Tanimoto similarity score of 0.662 is.

  • Session 1: Bioinformatics - A FASTA File, Sequence Object, and Sequence Extraction

    This YouTube video provides a taste of bioinformatics by introducing the FASTA file and simple operations with the file.

  • Session 2: Bioinformatics - Digital Analogues of Nucleic Acid Processes: Transcription and Translation

    This YouTube session discusses the chemical structure of nucleic acids (DNA and RNA) and the digital analogs of nucleic acid processes: transcription and translation.
