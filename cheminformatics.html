Cheminformatics

This lecture series offers a comprehensive introduction to cheminformatics — a multidisciplinary field at the at the intersection of chemistry, data science, and computer science, and a key component of the fourth paradigm of scientific discovery. It features hands-on use of the RDKit Python library for chemical structure visualization, molecular property extraction, structural pattern search, and QSPR/QSAR modeling. The series also introduces a range of molecular featurization techniques.

  • Python Basics for Chemists

    This YouTube session introduces key Python concepts tailored for chemists for their numerical computations and graphing, covering: 1. Assigning values to variables. 2. Performing operations with different variable types. 3. Utilizing popular Python libraries, including NumPy, Pandas, and Matplotlib.

  • Cheminformatics Session 0 Part 1: Visualizing Chemical Structure

    This YouTube session shows how to visualize chemical structures using Python's library, RDKit.

  • Cheminformatics Session 0 Part 2: Visualizing Stereoisomers

    This YouTube session explains how to visualize stereoisomers using Python and the RDKit library. It discusses R and S isomers and Z and E isomers.

    This YouTube session builds upon our understanding of stereochemistry. Additionally, we demonstrate techniques for visualizing molecular structures while incorporating their stereochemical details.

  • Cheminformatics Session 0 Part 4: Extracting & Searching Molecular Information

    This YouTube video explores an alternate approach to performing a pattern search and shows how to access and modify specific atoms and bonds within a molecule.

    This YouTube video shows how to perform a molecular pattern search by using the Python library, RDKit.
